# 工位调度大师 - 产品需求文档

## 1. 产品概述

一款单机节奏调度小游戏，玩家在连续体验场次之间安排工位清理、补料和下一场入场，必须在有限时间内让关键工位恢复。通过拖拽清理任务、调整优先级和触发补料完成安排。

- 主要目的：锻炼玩家的时间管理和任务调度能力
- 目标用户：休闲游戏爱好者、时间管理类游戏玩家
- 产品价值：提供轻松有趣的策略体验

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|---------|
| 玩家 | 无需注册 | 游戏游玩、本地成绩保存 |

### 2.2 功能模块

1. **主菜单页面**：开始游戏、教程、成绩记录、关卡选择
2. **游戏主界面**：任务清单、工位状态、倒计时条、控制按钮
3. **结算页面**：评分展示、关卡解锁
4. **教程页面**：游戏规则说明
5. **成绩页面**：本地保存的历史成绩

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主菜单 | 导航菜单 | 开始游戏、教程、成绩、关卡选择 |
| 主菜单 | 关卡选择 | 显示已解锁关卡、选择关卡开始 |
| 游戏主界面 | 倒计时条 | 显示剩余时间、时间进度 |
| 游戏主界面 | 工位状态面板 | 显示各工位清洁度、材料状态 |
| 游戏主界面 | 任务清单 | 待办任务列表、支持拖拽排序 |
| 游戏主界面 | 控制区 | 暂停/继续、触发补料、开始下一场 |
| 游戏主界面 | 事件提示 | 显示随机事件（缺件、污损、延迟、提前） |
| 结算页面 | 评分面板 | 清理完成率、补料准确率、延误时长、工位利用率 |
| 结算页面 | 综合得分 | 总分计算、星级评价 |
| 教程页面 | 规则说明 | 游戏玩法、操作指南、评分标准 |
| 成绩页面 | 历史记录 | 各关卡最佳成绩、历史记录 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝色（#1e3a5f）作为主色，橙色（#f97316）作为强调色
- **辅助色**：绿色表示正常状态，红色表示警告状态
- **按钮风格**：圆角矩形，带有轻微阴影，悬停时有缩放效果
- **字体**：使用现代无衬线字体，标题加粗
- **布局风格**：卡片式布局，清晰的信息层级
- **图标风格**：使用emoji图标增强视觉效果

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主菜单 | 导航菜单 | 大标题、渐变背景、卡片按钮 |
| 游戏主界面 | 倒计时条 | 进度条动画、时间数字 |
| 游戏主界面 | 工位状态 | 状态卡片、进度条、图标 |
| 游戏主界面 | 任务清单 | 可拖拽列表项、优先级标识 |
| 结算页面 | 评分面板 | 动画数字、星级展示、总分 |

### 4.3 响应式

- 桌面端优先设计
- 适配平板设备
- 拖拽操作优化

## 5. 关卡设计

### 关卡1：新手入门
- 时间：90秒
- 工位：3个
- 事件：无特殊事件
- 目标：熟悉基本操作

### 关卡2：材料危机
- 时间：80秒
- 工位：4个
- 事件：材料包缺件
- 目标：处理缺件问题

### 关卡3：清洁挑战
- 时间：70秒
- 工位：5个
- 事件：某工位污损严重
- 目标：优先处理重度污损工位

### 关卡4：双重压力
- 时间：60秒
- 工位：5个
- 事件：讲解员临时延迟 + 下一场提前到达
- 目标：灵活调整时间安排

## 6. 评分标准

| 评分项 | 权重 | 说明 |
|-------|------|------|
| 清理完成率 | 30% | 工位清洁度达标比例 |
| 补料准确率 | 25% | 正确补料的工位比例 |
| 延误时长 | 25% | 下一场入场延误时间扣分 |
| 工位利用率 | 20% | 工位有效使用比例 |
